# Bookloom

Express / EJS / MongoDB で作った、自分の読書を記録する本棚アプリです。

## 起動方法

MongoDB を起動した状態で、次を実行します。

```bash
npm start
```

ブラウザで `http://localhost:8081` を開いてください。サンプルデータを入れる場合は、先に `npm run seed` を実行します。

別のMongoDBを使う場合は `MONGODB_URI`、別ポートを使う場合は `PORT` を環境変数で指定できます。

## 主な機能

- 本の登録・一覧・詳細・編集・削除
- タイトル、著者、メモの検索
- 読書ステータスでの絞り込み
- ジャンル、評価、価格、メモ、お気に入りの記録
- 入力値検証、404画面、削除確認

## テスト
